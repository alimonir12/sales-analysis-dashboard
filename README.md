An interactive sales dashboard for exploring sales performance, orders, discounts, shipping costs, payment methods, regions, and products.

## Project Overview

This project transforms sales data into an interactive dashboard. KPI cards provide a quick summary, while charts and filters help explore trends and compare categories.

## Skills Demonstrated

- **Data exploration** — reviewed sales patterns across years and months.
- **Data cleaning** — prepared the dataset for analysis.
- **Pivot tables** — summarized data by time period, region, product, and payment method.
- **Pivot charts** — visualized trends and category comparisons.
- **Dashboard design** — combined key metrics, charts, and interactive filters.

## Dashboard Highlights

- Total sales
- Average discount
- Number of orders
- Average shipping cost
- Revenue by year and month
- Orders by payment method
- Top regions and products
- Sales by store location
- Filters for year, month, and promotion

## Tools

- Microsoft Excel
- PivotTables
- PivotCharts
- Interactive dashboard filters

## Getting Started

1. Download or clone this repository.
2. Open the Excel workbook in Microsoft Excel.
3. Use the dashboard filters to explore the available data.

## Project Purpose

This project demonstrates a practical data analysis workflow: exploring and preparing data, summarizing it with PivotTables, and presenting findings through an interactive dashboard.
